成果物 (Projects)

プロジェクト名：ユーザー管理Webアプリケーション

概要

ReactとTypeScriptを使用して開発した ユーザー情報を管理する簡易的なWebアプリケーションです。 REST APIを通じてユーザー情報の取得・登録・更新・削除を行う CRUD機能を実装しました。 また、API通信処理をサービス層に分離し、 画面表示とデータ処理を整理しています。

使用技術

  • React
  • TypeScript
  • Vite
  • REST API
  • Fetch API
